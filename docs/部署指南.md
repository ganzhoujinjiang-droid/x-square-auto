# 部署指南

目标环境：Oracle Cloud Always Free ARM（aarch64，2 核 / 11.65GB / 无 swap）或同架构 VPS。
全部镜像均有 linux/arm64 变体；原生模块（argon2）在容器 builder 阶段编译，宿主机无需工具链。

## 1. 前置

```bash
# Docker 与 Compose v2
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker

# 确认宿主机端口占用：443 已被既有服务独占，本系统只用 127.0.0.1:8443
ss -tlnp | grep -E ':(443|8443)\b'
```

## 2. 配置

```bash
git clone <repo-url> && cd x-square-auto
cp .env.example .env
```

必填项生成方式：

```bash
# APP_ENCRYPTION_KEY（32 字节 base64，丢失 = Token 永久不可解密，离线备份！）
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# SESSION_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# POSTGRES_PASSWORD / ADMIN_PASSWORD：强随机口令，ADMIN_PASSWORD ≥12 字符
openssl rand -base64 24
```

X Client ID/Secret、回调地址、Binance Square Key 的获取见 [X-App-申请指南.md](X-App-申请指南.md) 与 README。

## 3. 启动

```bash
docker compose up -d --build          # 首次构建约数分钟（2 核机器 next build 较慢属正常）
docker compose exec api pnpm --filter @x-square/database deploy   # 数据库迁移
docker compose exec api pnpm --filter @x-square/database seed     # 初始管理员
docker compose ps                     # 全部 healthy 才算完成
docker compose exec api node -e "fetch('http://127.0.0.1:4000/health').then(r=>r.json()).then(console.log)"
```

## 4. 暴露方式（§16.3 三选一）

**方案 A（推荐）**：宿主机 Nginx 增加 server 块，`server_name square.yourdomain.com; proxy_pass http://127.0.0.1:8443;`，TLS 由 Nginx/Cloudflare 终结。不动 Xray、不开新端口。

**方案 B**：Cloudflare 代理子域名回源 8443（需放行入站）。

**方案 C（调试）**：不暴露公网，`ssh -L 8443:127.0.0.1:8443 user@server` 后访问 http://127.0.0.1:8443 。

⚠️ 不要为腾出 443 而停止 Xray——那是既有生产服务。

## 5. 验收清单（设计文档 §24）

```text
□ 发一条 X → 30s 内出现在同步记录且 Binance 自动发布成功
□ docker compose restart worker → 不重复发布、不丢中断期间帖子
□ 后台「连接 X」→ 历史帖子零条同步，仅 baseline 落库
□ 模拟超时（临时把 publish 超时改 1ms）→ 任务进「待确认」且不自动重发
□ 数据库查询 SELECT * FROM x_accounts → 只有密文列
□ grep -RiE 'access_token|api_key' 日志目录 → 无凭据明文
```

## 6. 备份与恢复

- `pg_dump` 每日一次，复用服务器已有 site-worker 备份定时器，产物落 `/var/lib/site-worker/backups/`；
- Redis 开 AOF（compose 已配），仅作队列/会话，丢了可重建；
- **`.env` 与 APP_ENCRYPTION_KEY 单独离线备份**——不在任何自动备份范围内。

## 7. 常见排错

| 症状 | 原因 | 处置 |
|---|---|---|
| api 起不来：缺少环境变量 | .env 未填全 | 对照报错逐项补齐，进程拒绝半配置启动是特性 |
| X 账号 TOKEN_EXPIRED | refresh 失败退避耗尽 | 后台重新点「连接 X 账号」 |
| 持续 RATE_LIMITED | App Owner ≠ 被监控账号或请求过频 | 核对 Owned Reads 前提；间隔调大 |
| 发帖静默停止 | X 信用余额为负被阻止 | Developer Console 充值 + 设 Spending Limit |
| 待确认堆积 | Binance 侧网络抖动 | 逐条人工核对后再选择重试/标记 |
